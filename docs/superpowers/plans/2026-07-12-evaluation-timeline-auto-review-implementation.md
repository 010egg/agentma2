# AgentMa 评测时间线与自动审核实施计划

日期：2026-07-12

## 目标

为评测作业和尝试记录真实起止时间，在排行、运行详情和证据中展示耗时；将证据审核改为即时保存，并在全部候选用例组结论明确后自动完成运行。

## 步骤

1. 为作业和尝试增加幂等时间字段迁移，补齐领取、完成、失败、取消和租约恢复写入。
2. 扩展映射、报告排行和审核矩阵时间聚合。
3. 在细粒度审核写入后计算自动完成条件，并事务更新运行与审核分配状态。
4. 扩展审核 API 响应，返回审核事件、最新矩阵摘要和运行。
5. 前端增加耗时格式化、排行平均耗时、运行时间线、用例组和尝试起止时间。
6. 将用例与尝试审核改为点击即保存，增加单项保存状态，移除三个旧提交按钮。
7. 扩展存储和 API smoke，覆盖时间字段、自动通过、自动驳回和阻塞条件。
8. 运行 ESLint、生产构建、评测 smoke、API smoke 和配额回归，重启生产服务并验证线上资源。
