# 工具中心文件夹目录树设计

日期：2026-07-12

## 背景

`/tools` 已将“工具目录”和“MCP 连接”整合在同一路由下。当前工具目录使用横向 Tag 按钮和双列工具卡片，分类层级不直观，标签管理、搜索、工具浏览和注册操作同时占据首屏，整体显得零散。

本次优化将分类改为类似桌面文件资源管理器的纵向可折叠目录树，并统一 `/tools` 页面的间距和视觉层级。现有工具数据、权限规则、内部工具配置、MCP 连接能力及后端接口保持不变。

## 目标

- 将分类呈现为紧凑的纵向目录树，而不是横向标签或大尺寸分类卡片。
- 让分类、工具和工具详情形成清晰的父子层级。
- 降低首屏视觉噪声，突出“定位目录 → 浏览工具 → 查看详情”的主线。
- 保留搜索、分类管理、注册、编辑、删除、内部模型配置和 MCP 服务管理等现有能力。
- 在桌面端和移动端都保持可用，并支持键盘和辅助技术访问。

## 非目标

- 不修改工具、分类或 MCP 连接的数据模型。
- 不新增后端接口，不改变权限判定。
- 不重做 MCP 连接页的业务流程。
- 不引入拖拽排序、跨分类移动或多选批量操作。
- 不在本次工作中重构与工具页无关的全局样式。

## 页面结构

### 顶部视图切换

保留现有“工具目录 / MCP 连接”两个可深链的页签。页签仍由 `tab` 查询参数控制，只收紧尺寸、间距和选中态，使它与新的文件管理器式布局属于同一视觉系统。

### 工具目录工作区

桌面端采用两栏结构：

- 左栏为约 220–240px 的目录树，包含目录摘要、搜索框、分类节点和分类管理入口。
- 右栏为弹性内容区，包含面包屑、当前分类标题、摘要、工具列表、工具操作和详情。

目录树使用紧凑行高。分类节点由展开箭头、文件夹图标、分类名称和工具数量组成；展开后，工具作为缩进的文件项显示。分类不使用大卡片、横向标签或等宽布局。

右侧工具列表采用信息密度适中的列表行，主要字段为名称、说明、来源和关键权限状态。编辑、删除等低频操作在行操作或详情区域中出现，避免每行堆叠大量按钮。

### 现有功能安置

- 内部工具模型配置：保留租户管理员权限限制，放在对应工具详情中。
- 自定义工具编辑与删除：放在选中工具的详情操作区。
- 注册 MCP 工具：作为右侧标题区的主要操作。
- 分类管理：作为目录树底部或目录标题旁的次级操作，打开紧凑的管理区域。
- MCP 服务端管理：保留现有信息，在相关分类或工具详情下显示，不与目录导航争夺首屏空间。
- 工具 JSON 定义：点击工具后在右侧详情区展示，延续现有 `JsonViewer` 能力。

## 交互规则

### 展开与选择

- 点击展开箭头只改变分类的展开状态，不改变当前筛选。
- 点击分类行将其设为当前分类，并在右侧显示该分类的所有工具。
- 点击已展开分类下的工具子项，将其设为当前工具，并在右侧显示工具详情。
- 初次进入时默认选中“全部工具”视图；目录节点保持紧凑，不为“全部”创建大尺寸特殊卡片。
- 目录展开状态只属于前端视图状态，不写入现有工具数据。

### 搜索

- 搜索同时匹配工具名称、描述和分类名称，沿用不区分大小写的规则。
- 搜索期间自动展开包含匹配工具的分类。
- 右侧显示所有匹配结果，并保留其分类信息。
- 清空搜索后恢复搜索前的手动展开状态和当前分类选择。
- 无结果时在右侧显示明确的空状态，不隐藏目录树或管理入口。

### 分类管理

- 新建分类沿用现有前端持久化机制。
- 自定义分类支持重命名和删除；内置分类不可删除。
- 删除自定义分类时，所属自定义工具继续移动到“未分类”，保持现有行为。
- 分类操作使用显式按钮或菜单，不依赖双击等不易发现、移动端不可用的手势。

### 工具操作

- 点击列表行或目录中的工具文件项均可查看详情。
- 自定义工具可编辑、删除；内部工具和内置工具不显示不适用的操作。
- 所有行内按钮必须阻止触发父级选择事件。
- 保存、加载和删除的现有错误处理保持不变，错误应在相关区域附近显示；不新增全局错误状态。

## 响应式设计

- 宽屏：固定宽度目录树 + 弹性内容区。
- 中等宽度：目录树适当收窄，工具列表隐藏低优先级列并保留名称、说明和状态。
- 小于约 768px：目录树通过“目录”按钮展开为内容上方的可折叠面板；右侧内容变为单栏。
- 移动端目录面板限制最大高度并允许内部滚动，避免展开多个分类后占满屏幕。
- 移动端仍使用纵向树结构，不退化为横向分类标签。

## 视觉规范

- 继续使用项目现有的 Newsreader、JetBrains Mono、暖白背景和深色墨水色变量。
- 文件夹图标使用克制的暖黄色作为识别色，其余界面保持中性色。
- 目录节点行高约 28–32px，工具子项略矮并使用缩进表达层级。
- 选中态使用浅色背景和清晰文字对比，不依赖颜色作为唯一提示。
- 工具列表以细分隔线和轻微悬停反馈为主，避免厚重阴影和大圆角卡片。
- 动效仅用于目录展开、面板切换和悬停反馈，并遵循 `prefers-reduced-motion`。

## 可访问性

- 目录使用树形语义或等效的可访问结构，分类节点暴露展开状态。
- 展开按钮、分类选择和工具选择可分别通过键盘操作。
- 焦点样式清晰可见；图标按钮提供可读标签。
- 页签维持正确的 `tablist`、`tab`、`aria-selected` 和面板关联。
- 目录数量、来源和权限状态均提供文本，不只依赖图标或颜色。

## 实现边界

主要改动集中在：

- `dashboard/src/pages/Tools.tsx`：目录状态、搜索派生数据和新布局结构。
- `dashboard/src/App.css`：仅新增工具目录专用样式和响应式规则，并复用现有变量。

如组件复杂度增长，可在 `dashboard/src/components/` 中提取只服务于工具页的目录树和工具列表组件，但不进行无关页面重构。

## 验证

- 运行 TypeScript 构建，确认现有 `/tools?tab=mcp` 深链和工具目录编译通过。
- 验证分类展开、分类选择、工具选择、搜索、清空搜索和空结果状态。
- 验证自定义分类的新建、重命名、删除及“未分类”回退行为。
- 验证自定义工具注册、编辑、删除以及内部工具默认模型保存。
- 检查租户管理员和非管理员看到的操作是否符合现有权限。
- 使用键盘完成页签切换、目录展开和工具选择。
- 在桌面、平板和手机宽度下检查溢出、滚动和焦点可见性。
- 在 `prefers-reduced-motion` 下确认没有必要动画。

## 验收标准

- 分类以纵向可折叠目录树呈现，每个分类只占一行基础高度。
- 展开分类后，所属工具作为缩进子项显示。
- 右侧清晰展示当前分类的工具列表和选中工具详情。
- 搜索能够跨名称、描述和分类工作，并自动展开匹配目录。
- 现有工具管理、内部模型配置和 MCP 相关能力没有功能回退。
- 移动端保留纵向目录体验，页面无水平溢出。
- 构建通过，关键交互具备键盘和可访问语义。
