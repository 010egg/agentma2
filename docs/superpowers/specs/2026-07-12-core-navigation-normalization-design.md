# 核心导航名称与顺序统一设计

## 目标

统一左侧“核心”导航与总览星图的入口名称、顺序和图标映射，避免两个入口区域表达不一致。

## 导航定义

左侧核心导航固定为以下顺序：

1. 会话
2. Agent
3. 知识库
4. 技能
5. 工具
6. 记忆
7. 可视化
8. 总览

现有路由保持不变。每个名称继续使用与其功能对应的现有线性图标。

## 总览星图

总览页展示前七个功能入口，并与左侧导航保持相同的名称、顺序和图标。总览页不为“总览”自身创建重复的自链接节点。

原有管理类入口继续保留在“运维”导航中，不再混入总览星图。现有入口说明文字和配色尽量沿用，仅在名称变化导致语义不一致时同步调整。

## 实现范围

- 修改 `dashboard/src/components/Sidebar.tsx` 中“核心”区的名称和顺序。
- 修改 `dashboard/src/pages/Overview.tsx` 中总览星图的数据定义。
- 不更改路由结构、权限逻辑、页面组件或整体视觉风格。
- 不进行导航配置重构，降低与当前未提交改动冲突的风险。

## 验证

- 运行前端类型检查或生产构建。
- 检查左侧核心导航的八项名称和顺序。
- 检查总览星图的七个功能入口名称、顺序和图标映射。
- 确认各入口仍跳转到原有路由。
