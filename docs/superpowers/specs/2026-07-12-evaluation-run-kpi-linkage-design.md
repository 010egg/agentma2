# AgentMa 评测运行 KPI 联动设计

日期：2026-07-12

状态：已批准，待书面规格审阅

范围：让评测页顶部 KPI 随当前选中的评测运行联动；未选择运行时继续显示当前项目或全部项目的汇总指标。

## 1. 问题

评测页已经维护项目筛选和运行选择状态，但顶部 KPI 始终读取项目或全部项目的 `overview.metrics`。用户选择某次运行查看详情后，顶部仍显示多个运行的汇总值，容易将项目整体通过率、待审核数量和资源消耗误认为当前运行结果。

## 2. 已确认设计

- 未选择运行时，顶部 KPI 保持现状，展示当前项目或“全部项目”的汇总指标。
- 选择运行后，顶部 KPI 立即切换为该运行的布局和作用域，不等待运行报告返回。
- 关闭运行详情后，顶部 KPI 立即恢复为项目或全部项目汇总。
- 运行报告刷新时，运行级 KPI 随报告同步刷新。
- 报告加载期间不使用旧运行的报告计算新运行 KPI，也不回退项目汇总；运行列表已有的候选数和执行进度立即显示，其余字段使用固定尺寸加载占位。
- 本次使用现有运行报告在前端派生指标，不新增后端接口，不改变统计口径。

## 3. 运行级 KPI

选中运行后显示五项：

1. `候选 / 用例`：候选数量与审核矩阵中的候选用例组数量。
2. `执行进度`：终态作业数量占作业总数的比例，并显示完成数与总数。
3. `样本通过率`：当前运行审核矩阵的通过率；没有可评估样本时显示 `-`。
4. `待审核样本`：尚未人工审核或有效结论为 `needs_attention` 的候选用例组数量。
5. `Token / 成本`：当前运行全部候选排行的 Token 和美元成本合计。

运行级数据来源：

```text
候选数量       = report.run.candidates.length
用例组数量     = report.reviewMatrix.summary.total
执行进度       = report.run.progress 中终态作业数 / total
样本通过率     = report.reviewMatrix.summary.passRate
待审核样本     = reviewMatrix.groups 中未人工审核或 needs_attention 的组数
Token / 成本   = report.rankings 中 totalTokens 与 totalCostUsd 分别求和
```

终态作业包括 `completed`、`failed` 和 `cancelled`。总数为零时执行进度显示 `0 / 0` 和 `0%`。

## 4. 作用域提示

KPI 区域显示当前口径：

- 选中运行时显示运行名称，表明指标只属于该运行。
- 未选中运行时显示当前项目名称；选择“全部项目”时显示“全部项目”。

作用域提示使用现有紧凑样式，不增加新的卡片、弹窗或操作按钮。

## 5. 数据一致性与错误处理

- 只要存在 `selectedRunId` 就启用运行级 KPI 布局；只有 `report.run.id === selectedRunId` 时才使用报告数据。
- 切换运行时先清除或忽略旧报告，并立即使用运行列表数据填充候选数与执行进度。
- 新报告加载失败时保留错误提示，不把旧报告或项目汇总数据显示为当前运行；缺少的运行级字段显示 `-`。
- 数值格式沿用现有 `formatNumber`、百分比和成本格式。
- 运行详情轮询返回新数据后，KPI 与排行、证据矩阵使用同一份报告，避免不同步。

## 6. 实现边界

- 在 `dashboard/src/pages/Evaluations.tsx` 内增加运行级 KPI 派生数据和作用域选择。
- 优先复用现有报告类型与格式化函数，不新增共享抽象。
- 不修改 `/api/evaluations/overview` 和运行报告 API。
- 不修改项目级和全部项目级指标定义。
- 不修改运行列表、候选排行、证据审核和自动完成逻辑。

## 7. 验收标准

- 未选择运行时，顶部 KPI 与当前项目筛选联动。
- 选择运行后，五项 KPI 全部切换为该运行的数据，并显示运行名称。
- 选择另一运行后，不会短暂显示上一运行 KPI，也不会闪回项目或全部项目汇总。
- 关闭详情后，KPI 立即恢复项目或全部项目汇总。
- 轮询期间运行进度、通过率、待审核数量、Token 和成本能同步更新。
- 无样本、无排行、失败运行和旧报告字段缺失时页面不报错。
- 定向 ESLint、TypeScript/生产构建和评测页面 smoke 通过。

## 8. 非目标

- 不新增时间、成本或通过率的后端聚合口径。
- 不把运行级 KPI 写入数据库。
- 不增加 KPI 趋势图、跨运行对比或导出功能。
- 不改变用户选择项目和运行的持久化方式。
